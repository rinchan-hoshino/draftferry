# 稿渡（DraftFerry）

稿渡把 Markdown 文章、里面用到的本地图片和 Mermaid 图导入百家号图文编辑页。只做百家号，不自动保存或发布，导完请自己检查后再发。

[安装或更新稿渡](https://acv.k-neco.com/tools/draftferry.user.js) · [更新记录](CHANGELOG.md)

## 安装

1. 安装 Tampermonkey（Chrome 版 5.3 以上），并在扩展设置里允许用户脚本。
2. 打开上面的安装链接，确认安装即可。以后会自动更新。

## 使用

1. 登录百家号，进入图文编辑页。
2. 点右下角「导入 Markdown」。
3. 把 `.md` 和文章里用到的图片一起拖进面板，或点虚线框选择；也可以直接把 Markdown 粘贴到下面的输入框。
4. 点「导入」。导入好后面板会自动收起，接着直接拖下一篇即可，不用刷新页面。

标题取文章里第一处一级标题（`# 标题`），标题框会自动填上，正文里不再重复这一行。没有一级标题时用文件名。

## 出错怎么办

- 面板里会写一行原因。图片找不到时正文里会留下 `[缺图：文件名]`，补拖图片后重新导入即可。
- Mermaid 图渲染失败时会保留成代码块，面板里会提示。
- 标题没填进去时面板会报错，请手动粘贴标题。
- 其它报错点「复制诊断」，把复制的内容发给铃酱。

## 开发

```sh
npm ci
npm run check
```

构建产物是 `dist/draftferry.user.js`。源码在 `src/`，单元测试在 `test/`，示例稿件在 `examples/`。以前八个平台的代码放在 `legacy/`，只作参考。
