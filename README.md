# 稿渡（DraftFerry）

稿渡将 Markdown、本地图片和 Mermaid 图表填入八个内容平台。当前版本 **0.6.6 Preview**，选择文件后立即导入；微信公众号使用金色标题标记与中性灰正文排版，其他平台沿用自身排版，完成后由使用者检查并手动保存或发布。

[安装或更新稿渡](https://acv.k-neco.com/tools/draftferry.user.js) · [本版变化](CHANGELOG.md)

## 安装与使用

1. 安装 Tampermonkey 5.3+，在扩展设置中启用“允许用户脚本”（较早的 Chrome 可启用开发者模式）。
2. 打开上方固定安装链接，核对名称为“稿渡 · Markdown 一键排版（Preview）”。已安装的用户可从同一链接更新。
3. 登录平台并进入文章或商品编辑页；开源中国需先切到 MD 编辑器。
4. 点击“导入 Markdown”，选择一个 `.md` 或 `.markdown` 文件，同时选中引用的本地图片。入口默认位于右侧中部，可拖动手柄调整位置，各网站分别记忆。
5. 已有内容时确认是否继续。写入期间目标编辑区域暂时锁定，完成或报错后解除。
6. 检查标题、正文、图片、表格和 Mermaid，再手动保存、预览或发布。

平时只显示紧凑的导入按钮。导入期间显示当前稿件、目的地和处理状态，可随时收起；收起不会中断任务。成功后自动收起并恢复“导入 Markdown”，可以直接选择下一篇，不保留已完成状态或上一篇的面板信息；平台里的文章保留，仍需手动检查与保存。

缺图时点击“补选图片”，补齐后自动继续，不必重新选择稿件。遇到失败可重试，已完成的读取和图表转换会复用；腾讯、知乎还会复用同一目标编辑器中已成功的图片上传。导入可以暂停，页面内切换后保留尚未完成的稿件，回到编辑页点击“继续导入”即可；刷新或关闭网页会结束此会话。

`⋯` 更多菜单提供“导入另一篇”“恢复默认位置”和“下载诊断”；诊断不含正文、标题、登录凭据或控件值。拖动手柄获得键盘焦点后，也可用方向键微调位置。

## 支持的平台

| 平台 | 使用说明 |
| --- | --- |
| 知乎 | 上传本地图片和 Mermaid，再完成 Markdown 解析 |
| 微信公众号 | 填入标题及富文本正文 |
| 开源中国 | 先手动切到 MD 编辑器 |
| 百家号 | 填入标题及富文本正文 |
| 今日头条 | 填入正文，图片交由平台处理 |
| 搜狐号 | 填入标题、正文，保留表格及独立 Mermaid 图块 |
| 阿里云市场 | 只填入产品详情，并由平台上传图片 |
| 腾讯云市场 | 先上传图片，再整篇替换商品详情；上传失败保留原文 |

云市场不会修改商品名称或其他基础资料。平台可能调整自身支持的排版；稿渡不会自动保存或发布。腾讯若无法确认编辑器接口，会在改动正文前停止并提示下载诊断。

## 转换规则

- 第一处一级标题用作文章标题，不重复放进正文。
- Mermaid 转为白底 PNG；重复图表复用有界缓存。
- 本地图片可与 Markdown 一起选择，也可缺图后补选；不能确定对应关系的重名图片不会被静默替换。
- 原始内嵌 HTML 先清理再转换；支持 GFM 表格、列表和代码块。
- 微信使用金色标题标记、浅灰引用与表格，正文保持深灰，并保留小标题的大小层级与加粗；其他平台沿用自身排版。
- 搜狐支持两级正文标题，通常将 `##`、`###` 对应到这两级；更深层级保留为加粗小标题。正文仍含 `#` 标题时，按 `#`、`##` 对应两级。
- 切换页面后暂停当前导入，避免把所选文件写入另一篇文章。继续时重新定位编辑器；目标变化后不复用旧目标的上传结果。

## 开发

```sh
npm ci
npm run check
```

构建产物为 `dist/draftferry.user.js`。完整检查需要本机 Chrome/Chromium，可用 `DRAFTFERRY_CHROME_PATH` 指定路径。模块说明、验证边界和发布步骤见 [维护文档](docs/architecture.md)。
