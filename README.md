# 搜狐号 Markdown 一键排版

给夫人使用的 Tampermonkey 用户脚本：在搜狐号文章编辑页选择 Markdown，自动转换排版、将 Mermaid 栅格化成 PNG，并填入标题和正文。

脚本**不会**自动保存、发布，也不会读取或导出登录凭据。

## 当前状态

- 本地转换与 Quill 编辑器原子注入/回滚边界已有自动化测试。
- 真实搜狐号的“填入 → 手动保存 → 预览”仍需夫人在自己的账号中验收。

## 安装

1. 安装 Tampermonkey 5.3 或更高版本。
2. Chrome 138+：打开 Tampermonkey 的扩展详情，启用“允许用户脚本”；若没有该开关，则在扩展管理页启用“开发者模式”。
3. 在 Tampermonkey 中导入 [`dist/sohu-markdown.user.js`](dist/sohu-markdown.user.js)。
4. 确认脚本仅匹配 `https://mp.sohu.com/*`。

## 使用

1. 登录搜狐号并进入文章编辑页。
2. 点击右下角的“导入 Markdown”。
3. 选择一个 `.md`/`.markdown` 文件；若正文引用本地图片，同时选中对应图片文件。
4. 等待脚本填入标题和正文。
5. 由夫人检查预览，然后手动保存或发布。

为避免误覆盖，标题或正文已有内容时脚本会拒绝导入，请先新建空白文章。若搜狐拒绝或只接受部分结构，脚本会撤销本次填入并明确报错；此时请刷新编辑页后再继续。

## 首版支持范围

- 标题、段落、粗体、链接、列表、引用和分隔线；
- Markdown 表格与代码块；
- `http(s)` 图片，以及与 Markdown 一起选择的本地图片；
- `mermaid` 代码块自动转换为白底 PNG；
- 第一处一级标题作为搜狐标题，不重复放入正文。

## 已知边界

- 搜狐保存时是否保留所有表格、PNG 和内联样式，必须以真实账号预览为准。
- 首次真实测试还需确认搜狐页面是否暴露可由 `Quill.find()` 取得的编辑器实例；若取不到，脚本会在改动正文前停止。
- 搜狐页面结构变化后，标题框、`.ql-container` 或 `.ql-editor` 边界可能需要更新。
- 首版不支持其他平台、不上传云端、不自动保存或发布。
